## CodeBuild webhook addition

Local proposal checked November 22, 2026: one on-demand Linux x86_64 small CodeBuild project, GitHub App/CodeConnections, one private S3 release-control bucket, CloudWatch Logs with seven-day retention and one customer-managed KMS key. No CodePipeline, CodeDeploy, reserved compute, Docker image server, NAT gateway or additional EC2. These services/settings are not provisioned by this change and require operation-specific approval and account availability checks. See [setup](codebuild-develop.md).

The public [CodeBuild pricing page](https://aws.amazon.com/codebuild/pricing/) publishes a Linux small example at $0.005/build minute and a conditional shared monthly allowance. **The exact Sydney rate and the account's applicable allowance have not been verified.** Use $0.01/minute only as a provisional planning ceiling; verify the selected regional compute price is at or below it before enabling the webhook. Do not assume unused free minutes or credits guarantee zero cost. Every triggered run, including docs-only, failed, stale and waiting-for-lock runs, consumes billed time. Queue/lock timeouts and webhook actor/branch restrictions reduce exposure but are not a monthly spending cap.

For this workload, replace the earlier **base-only $18 allowance** with a **combined $19.50 planning allowance**, leaving $0.50 below the $20 ceiling before other spending and tax. Do not add $2.80 on top of the old $18 allowance and treat it as approved: that would exceed the budget. This revised combined allowance has limited headroom and is a proposal, not verified account spend or approval. A six-minute average may be too low for the actual dependency/Docker/frontend build; if measured usage, current regional rates, artifact sizes, other account spending or tax exceed the model, reduce build frequency/duration/retention or stop before projected monthly spend exceeds $20. Do not upgrade the account to fix service or quota limits.

Stop if the AWS plan is inactive, expired or unverifiable, if verified remaining USD credits are below $20, if a required operation could upgrade the account or if current spend plus projected additions exceeds $20 for that month. The AWS estimate, alert state and Terraform validation cannot substitute for the verified plan state and exact approval.
